# Changelog

## 2026-09-25 — Sahifa-level loading skeletonlar

- Home sahifasi endi o'z layout'iga mos skeleton ko'rsatadi (`HomePageSkeleton`):
  sarlavha + kategoriya chips + video grid.
- Explore sahifasi endi o'z layout'iga mos skeleton ko'rsatadi
  (`ExplorePageSkeleton`): sarlavha + chips + sort select + video grid.
- Subscription sahifasi endi o'z layout'iga mos skeleton ko'rsatadi
  (`SubscriptionsPageSkeleton`): sarlavha + kanal avatarlari qatori +
  video grid (oldingi faqat video grid edi).
- `Skeleton` komponenti endi `style` prop'ini qabul qiladi.
- Yangi yordamchi skeletonlar: `VideoGridSkeleton`, `ChipsSkeleton`,
  `ChannelRowSkeleton`.
